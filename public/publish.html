How it works

Phones go live, everyone watches

Each camera phone streams to YouTube (and Facebook as a backup) with the free Larix app. Paste each live link below and press Publish: our website plays them in about 30 seconds.

Publish key

Not set

One-time: create the key on github.com (3 minutes)
  1. On github.com (signed in) → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: rangvaasa publish. Expiration: 30 days.
  3. Repository access: Only select repositories → live-brodcasting.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copy it, paste it below. It stays only on this phone.

Camera phones

Larix Broadcaster

1

Get the app

Install Larix Broadcaster

Free on Play Store and App Store.

2

YouTube (each angle)

Schedule a stream

YouTube Studio → Create → Go live → Manage → Schedule stream. Title e.g. "RANGVAASA · Main stage", visibility Public or Unlisted, allow embedding. Choose a new stream key for each angle. Copy the stream key (for Larix) and the share link (paste above).

3

Facebook (main camera)

Backup copy

facebook.com/live/producer → Go live → Streaming software → copy the stream key. After going live, copy the video's link and paste it above for that angle.

4

In Larix

Add connections

Settings → Connections → +. Name "YouTube", URL:

rtmp://a.rtmp.youtube.com/live2/STREAM-KEY

Add another, "Facebook", URL:

rtmps://live-api-s.facebook.com:443/rtmp/STREAM-KEY

Tick both connections to stream to both at once.

5

Video settings

720p, 30 fps

Settings → Video: 1280×720, 30 fps, bitrate 2500 kbps (1500 if streaming to both on weak Wi-Fi), keyframe frequency 2 s. Audio: AAC 128 kbps.

6

On the night

Landscape, plugged in

Hold the phone sideways, power bank on, Do Not Disturb on, then the red button in Larix.
